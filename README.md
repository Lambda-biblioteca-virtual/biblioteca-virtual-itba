# Biblioteca Virtual ITBA

Primera version de una pagina web para organizar bibliografia, parciales viejos,
resumenes, guias y otros materiales de estudio para estudiantes del ITBA.

## Como verla en tu computadora

Abrir el archivo `index.html` en un navegador.

## Como publicarla gratis

Este proyecto esta preparado para subirse a GitHub y publicarse con GitHub Pages.
