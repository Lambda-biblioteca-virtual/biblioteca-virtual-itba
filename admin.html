Panel admin

Cargar materiales para la biblioteca.

En esta version gratis con GitHub Pages, el panel prepara la ficha del material. Para que quede online para todos, despues hay que subir el archivo al repositorio y publicar el cambio.

Como entrar

Entras desde el boton Admin del menu o escribiendo /admin.html al final del dominio.

Clave temporal: itba-admin. Esto no es seguridad real; solo evita cambios accidentales mientras la web sea estatica.

Resultado

Completa el formulario para generar la ficha.
